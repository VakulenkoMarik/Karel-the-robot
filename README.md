# 🤖 ZAP Labs — Technical University of Košice (TUKE)

This repository contains lab assignments for the **Fundamentals of Algorithmic & Programming (ZAP / Základy algoritmizácie a programovania)** course at **KPI FEI TUKE**.

The project is developed in a Linux/C environment and includes algorithmic exercises, **Karel the Robot** control programs, and terminal-based logic games.

---

## 📚 Repository Structure

| Folder | Description | Tech / Topics |
|---|---|---|
| 📂 \`lab02/\` | Karel the Robot: Basic commands and tasks (e.g., \`stairs\`) | C, \`karel.h\`, Makefile |
| 📂 \`lab03/\` | *(In progress / Upcoming assignments)* | C |

---

## 🛠️ Requirements & Setup

To compile and run the code, you need:
* **GCC** compiler
* **Make** utility
* **Karel the Robot** library (included in the repo)

### Building and Running (Example for `lab02`):

1. Navigate to the specific lab directory:
   \`\`\`bash
   cd lab02
   \`\`\`

2. Compile using the Makefile:
   \`\`\`bash
   make
   \`\`\`

3. Run the executable:
   \`\`\`bash
   ./stairs
   \`\`\`
